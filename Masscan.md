**Masscan** — это высокоскоростной сканер портов для IP‑адресов. Его ключевая особенность — способность сканировать огромные сетевые пространства (в т. ч. весь IPv4‑интернет) за считанные минуты.

**Основные характеристики:**

- Скорость: до 25 млн пакетов в секунду (весь интернет по одному порту на IP можно просканировать за 3 минуты).
    
- Тип сканирования: асинхронное (stateless) — отправляет пакеты без ожидания ответа, параллельно прослушивает ответы.
    
- Результат: похож на вывод `nmap`, но фокусируется только на обнаружении открытых портов.
    
- Гибкость: поддерживает произвольные диапазоны IP‑адресов и портов.
    
- Стек TCP/IP: кастомный (не использует системный), что требует специальных настроек при работе.
    

---

# Отличия от Nmap

|Параметр|Masscan|Nmap|
|---|---|---|
|Назначение|Быстрое обнаружение открытых портов на больших сетях|Детальное сканирование хостов, определение служб, ОС, уязвимостей|
|Скорость|Очень высокая (миллионы пакетов/сек)|Низкая/средняя (зависит от типа сканирования)|
|Тип сканирования|TCP SYN (stateless)|TCP SYN (stateful) или TCP Connect|
|Точность|Может пропускать порты при высокой скорости|Высокая (stateful‑подход надёжнее)|
|Определение версий/ОС|Ограниченно (`--banners`)|Отлично|
|Поддержка скриптов|Нет|Обширная (NSE)|
|Сложность использования|Проще для базового сканирования|Более сложный из‑за множества опций|

Masscan дополняет Nmap: первый — для **широкой** разведки, второй — для **глубокого** анализа.

# Установка

**Linux (Debian/Ubuntu):**

```bash
sudo apt install masscan
```

**RHEL/CentOS/Fedora:**

```bash
sudo yum install masscan  # для старых версий
sudo dnf install masscan  # для новых версий
```

**macOS:**

```bash
brew install masscan
```

**Windows:** через WSL (Windows Subsystem for Linux).

**Из исходников:**

```bash
git clone https://github.com/robertdavidgraham/masscan
cd masscan
make
```

# Базовый синтаксис

```bash
masscan <цели> -p<порты> --rate <скорость> [опции]
```

**Указание целей:**

- Одиночный IP: `192.168.0.1`.
    
- Диапазон: `10.0.0.1-10.0.0.100`.
    
- CIDR: `0.0.0.0/0` (весь IPv4).
    
- Несколько целей: `10.0.0.0/8,192.168.0.1` или отдельными аргументами.
    

**Порты (`-p` или `--ports`):**

- Один порт: `-p80`.
    
- Список портов: `-p22,80,443`.
    
- Диапазон портов: `-p1-1024`.
    

**Скорость (`--rate`):**

- По умолчанию: 100 пакетов/сек.
    
- Рекомендуемая для тестирования: `--rate 10000` (10 тыс. пакетов/сек).
    
- Максимальная: до 25 млн пакетов/сек (зависит от сети и оборудования).

# Основные опции

- `--banners`: попытка захвата баннеров (ограниченная поддержка).
    
- `--exclude <IP>`: исключение IP‑адресов из сканирования (можно использовать несколько раз).
    
- `--excludefile <файл>`: чтение списка исключений из файла.
    
- `-e <интерфейс>`: выбор сетевого интерфейса.
    
- `--source-ip <IP>`: указание исходящего IP‑адреса.
    
- `--wait <сек>`: ожидание ответов после завершения отправки (по умолчанию 10 секунд).
    
- `-oX <файл>`: вывод в формате XML.
    
- `-oG <файл>`: вывод в «grepable» формате.
    
- `-oJ <файл>`: вывод в JSON.
    
- `-oL <файл>`: простой текстовый формат.
    
- `--resume <файл>`: возобновление прерванного сканирования (сохраняется в `paused.conf` при `Ctrl+C`).
    
- `-c <файл>`: использование конфигурационного файла.
    
- `--echo`: генерация конфигурационного файла из текущих настроек.

# Примеры использования

1. **Сканирование порта 80 в частной сети:**

```bash
masscan 10.0.0.0/8 -p80 --open-only
```

2. **Сканирование портов 22, 80, 443 в подсети с захватом баннеров:**

```bash
masscan 192.168.1.0/24 -p22,80,443 --rate 10000 --banners -oJ results.json
```

3. **Исключение адресов и сохранение в XML:**
   
```bash
masscan 172.16.0.0/12 -p1-1000 --rate 5000 --exclude 172.16.1.1 --exclude 172.16.2.254 -oX scan.xml
```

4. **Возобновление прерванного сканирования:**
  
```bash
masscan --resume paused.conf
```

5. **Генерация конфигурационного файла:**
   
```bash
masscan -p1234 --echo > config.conf
```

6. **Сканирование с указанием интерфейса и исходящего IP:**
 
```bash
masscan 192.168.1.0/24 -p80 --rate 1000 -e eth0 --source-ip 192.168.1.100
```
